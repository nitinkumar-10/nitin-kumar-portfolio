# Nitin Kumar – Cinematic Data Science Portfolio V4

A premium dark, animated static portfolio site for Nitin Kumar focused on Data Science, AI and Machine Learning.

## V4 upgrades
- Stronger animated hero experience
- Preloader screen
- Cursor glow effect
- Scroll progress bar
- Premium grid background + particle network
- Netflix-style horizontal project rail with auto sliding
- Tilt/parallax cards and cinematic reveal animations
- Big-tech-inspired design cues (Microsoft, Netflix, Google, Oracle, Meta)
- Real internship project screenshots and report

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.

## Edit details
Update personal info and links inside `config.js`.
